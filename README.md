# DailyCost · 每日花费

纯本地的消费日均计算器 —— 把购买价格折算成「每天花多少钱」，让每一笔钱被看见。

## 核心公式

```
日均成本 = (购买价格 − 残值) ÷ 使用天数
```

## 特点

- **本地优先**：零账号、零上传、零追踪；数据仅存本机并以 **SQLCipher 加密**（密钥存系统安全存储）
- **六种计价模式**：固定天数 / 到期日 / 订阅周期 / 实际天数 / 按次 / 按小时
- **两种折旧曲线**：直线折旧 / 余额递减（只影响剩余价值展示，不改变日均公式）
- **TCO 总拥有成本**：维护/能耗/保险/配件一并计入日均；**分期含利息**（等额本息）；**多币种**（离线汇率表）
- **首页总览**：今日日均总支出大数字 + 环比 + 在用物品卡片（日均价、进度条、状态）
- **试算器**：输入价格与时长即时算日均，趣味对比「≈ N 杯咖啡」
- **深色模式**：跟随系统 / 手动切换，持久化保存
- **应用内更新**：检测 GitHub 最新版本并自动下载安装包

## 隐私

- **不收集、不上传任何数据**，无账号、无统计、无追踪。
- 唯一的联网行为：**检查与下载应用更新**（仅访问 GitHub），可在「设置 → 自动检查更新」中关闭；关闭后应用完全离线运行。
- 全部数据保存在本机 SQLite，使用 SQLCipher 加密，密钥由系统安全存储（Android Keystore / iOS Keychain）保管。
