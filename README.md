# DailyCost · 每日花费

纯本地的消费日均计算器 —— 把购买价格折算成「每天花多少钱」，让每一笔钱被看见。

## 核心公式

```
日均成本 = (购买价格 − 残值) ÷ 使用天数
```

## 特点

- **纯本地**：零联网、零账号、零上传，数据仅存本机 SQLite，应用不申请任何网络权限
- **六种计价模式**：固定天数 / 到期日 / 订阅周期 / 实际天数 / 按次 / 按小时
- **两种折旧曲线**：直线折旧 / 余额递减（只影响剩余价值展示，不改变日均公式）
- **首页总览**：今日日均总支出大数字 + 环比 + 在用物品卡片（日均价、进度条、状态）
- **试算器**：输入价格与时长即时算日均，趣味对比「≈ N 杯咖啡」
- **深色模式**：跟随系统 / 手动切换，持久化保存
